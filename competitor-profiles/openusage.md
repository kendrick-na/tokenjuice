# OpenUsage — Quick Profile

후속 출시 재확인: [근거 노트](raw/openusage/2026-10-11-release-recheck/scrapes/distribution.md)와 [통합 비교 §7~§10](../docs/COMPETITOR_GAP_MAP_2026-10-11.md#7-경쟁사-출시-채널과-가격-비교)을 우선 적용한다. 가격/채널/개인정보의 재확인 결과이며 실제 설치 검증은 아니다.

확인일: 2026-10-11 · [공식 출처](https://openusage.sh/)

대상(카피에서 추론): 여러 코딩 도구를 동시에 쓰는 터미널 사용자.

## 확인한 서비스 내용

렌더링된 페이지는 34 providers. terminal dashboard·statusline·로컬 history를 소개한다. provider별 지원 범위가 다르다.

## UI/UX 관찰

픽셀 로고·모노스페이스·적은 강조색이 개발자 제품의 정체성을 만든다. 현재 브라우저에서 영상은 재생되지 않았다.

## TokenJuice 개선 시사점

provider 수 경쟁보다 연결 정확성과 작업 연속성에 집중. 기존 기획서의 35+를 현재 확정 수처럼 사용하지 않는다.

SEO/트래픽/전환율은 수집하지 않았다. 공개 기능 설명과 실제 동작 검증은 다르다. 계정 연결·결제·설치는 수행하지 않았다.
근거: [원본 수집 노트](raw/openusage/2026-10-11/scrapes/home.md).

## 2026-10-13 공개 첫 화면 후속

어두운 바탕·픽셀 로고·모노스페이스의 개발자 정체성과 설치 앵커/문서 CTA를 직접 관찰했다. 모바일 설치 앵커 y533/h41. terminal 실제 실행이나 더 많은 provider 지원을 검증한 것이 아니다.

이번 범위는 UI 첫 사용자 과제다. 기능·가격의 이전 확인일은 유지하며 SEO/전환 지표는 없다.
