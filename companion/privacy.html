수집하지 않는 정보

TokenJuice Pocket은 계정 생성, 로그인, 분석 SDK, 광고, 원격 측정, 서버 API를 사용하지 않습니다. 대화 초안 기능을 선택한 경우에만 사용자가 지정한 파일의 원문을 브라우저 메모리에서 읽습니다. 가져온 원문·스냅샷·요약·비밀값을 서버로 전송하지 않습니다.

이 기기에 저장되는 정보

사용자가 파일 선택으로 직접 가져온 TokenJuice 스냅샷 v1만 이 브라우저의 Local Storage에 저장합니다. 스냅샷에는 계정 별칭, quota 이름·퍼센트·리셋 시각, 데이터 신뢰 상태와 생성 시각이 들어갈 수 있습니다. 암호화 번들을 가져온 경우 암호는 이 브라우저에서 복호화에만 쓰이며 저장하지 않습니다.

checkpoint와 재개 안내

직접 선택한 metadata-only checkpoint는 프로젝트·브랜치·모델·컨텍스트 숫자·저장 시각만 화면 메모리에서 처리합니다. 알 수 없는 필드와 파일에 담긴 nextAction은 표시하거나 복사하지 않습니다. checkpoint를 Local Storage에 저장하거나 서버로 보내지 않으며 새로고침하면 화면에서 사라집니다. 원본 파일의 진위나 메타데이터가 민감하지 않다는 것을 보증하지 않으므로 공유 전 확인하세요.

재개 안내를 복사하거나 텍스트/JSON 파일로 저장하는 것은 사용자가 버튼을 눌렀을 때만 수행합니다. 클립보드와 다운로드한 파일은 다른 앱에서 사용될 수 있으므로 사용자가 관리합니다. 작업의 의미·최근 파일·프롬프트·코드를 자동 요약하거나 실제 세션을 실행하지 않습니다.

선택한 대화의 자동 추출 초안

사용자가 파일 선택 버튼을 눌러 지정한 한 세션의 대화 JSON·JSONL·텍스트(8 MiB 이하)에서 사용자·AI 발언만 추출합니다. 코드 블록, 도구 실행 결과, 알려진 비밀값 패턴은 제외하지만 모든 민감정보를 탐지할 수는 없습니다. 최근 200개 메시지, 각 700자까지의 근거를 사용하며 누락·잘못된 완료 주장이 있을 수 있습니다. 생성형 AI 호출이나 파일/브랜치 복원은 하지 않습니다.

원문·초안·근거는 Local Storage에 저장하지 않습니다. 검토 확인 후 버튼을 눌러 저장하는 JSON에는 수정한 네 항목만 포함하며 원문·근거 목록·파일명·세션 ID는 제외합니다. 새로고침 또는 ‘초안과 근거 지우기’로 화면 메모리를 비웁니다. 다운로드 파일은 사용자가 직접 관리하며 새 세션에 붙여넣기 전에 실제 변경 파일을 확인하세요.

삭제

계기판의 이 기기에서 삭제를 누르면 저장된 스냅샷을 즉시 삭제합니다. 브라우저의 사이트 데이터 삭제도 같은 효과가 있습니다. 앱은 서버에 복사본을 만들지 않으므로 별도 삭제 요청 대상이 없습니다.

재개 상세의 화면에서 지우기는 메모리의 checkpoint와 안내만 지우며, 스냅샷과 이미 다운로드한 파일·클립보드는 바꾸지 않습니다.

네트워크

처음 페이지를 열 때 정적 HTML·CSS·JavaScript·아이콘을 호스팅 서비스에서 받아 오프라인 캐시에 저장할 수 있습니다. 가져온 스냅샷 데이터와 암호는 네트워크 요청의 본문이나 URL에 포함하지 않습니다.
