01 · MACOS

설치하고 메뉴바 확인

SwiftBar와 Bun을 설치한 뒤 TokenJuice 플러그인을 메뉴바에 등록합니다.

CCB_YES=1 ./install.sh

설치 뒤에는 우측 상단 메뉴바에서 배터리를 확인하세요. 보이지 않으면 아래 진단을 실행합니다.

./install.sh --doctor

진단은 Bun·SwiftBar·플러그인·엔진 상태만 읽습니다. 앱을 새로 열거나 권한을 바꾸지 않습니다.

02 · WINDOWS

설치하고 트레이 확인

PowerShell에서 설치한 뒤 시계 옆 ^ 메뉴를 열어 TokenJuice 아이콘을 확인하세요.

cd windows && .\install.ps1

Python과 Bun이 필요하며, 설치 후 시스템 트레이에서 상태를 확인합니다.

03 · POCKET

휴대폰에서 상태 확인

Mac에서 --export-widget-snapshot으로 만든 파일을 Pocket에 직접 가져옵니다. Safari/Chrome의 “홈 화면에 추가”를 사용할 수 있습니다.

Pocket은 자동 동기화·앱스토어 배포가 아닌, 로컬 스냅샷 기반 공개 베타입니다.

FAQ

자주 묻는 질문

일반 AI 사용자도 필요한가요?

주로 Claude Code·Codex를 자주 사용하고, 한도나 컨텍스트 때문에 작업이 끊긴 경험이 있는 사용자를 위한 도구입니다.

자동으로 provider를 바꾸나요?

아니요. 상태와 안전한 다음 행동만 안내하며 compact·전환·커밋·배포를 대신 실행하지 않습니다.

Pocket이 자동 동기화되나요?

아니요. snapshot은 사용자가 직접 전달합니다. 자동 CloudKit 동기화와 App Store·Google Play 배포는 아직 제공하지 않습니다.

설치했는데 메뉴바에 보이지 않아요

저장소 폴더에서 ./install.sh --doctor를 실행하세요. 실패한 단계와 다음 행동을 보여주며, 계속되지 않으면 피드백을 남겨주세요.

릴리스 파일은 어디서 받나요?

GitHub Releases에서 확인할 수 있습니다. Windows exe는 릴리스 workflow가 생성합니다.
