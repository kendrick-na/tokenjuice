# TokenJuice 로컬 AI 요약 실행 안내

한 대화의 발언을 확인하고 선택적으로 Anthropic에 보내 작업 인계 초안을 만드는 개발 후보다. 공개 Pocket의 로컬 추출과 다르며, 실제 모델의 품질 평가와 신규 사용자 검증을 거친 출시 제품은 아니다. 기본 설치나 메뉴바 실행으로 자동 시작하지 않는다.

## 실행 조건

현재 Bun과 POSIX private 파일 권한을 지원하는 macOS/Linux에서만 실행한다. Windows 예산 저장은 ACL 구현 전까지 거부한다. 별도 Anthropic API 키가 필요하며 Claude 구독 자격증명이나 웹 쿠키를 읽지 않는다. API 비용은 구독과 별개다.

운영자가 모델 지원 여부와 입력·출력 가격을 확인하고, 키를 `TOKENJUICE_SUMMARY_API_KEY` 실행 환경에 안전하게 제공해야 한다. 키를 저장소·설정 JSON·URL·명령 기록·스크린샷에 넣지 않는다. 아래 설정 파일은 키를 포함하지 않아야 한다.

| 설정 필드 | 값과 조건 |
|---|---|
| `model` | 사용할 실제 모델 ID. 자동 기본 모델 없음 |
| `maxOutputTokens` | 출력 제한 256~2048, 생략 시 코어 기본값 1024 |
| `budget.model` | `model`과 동일 |
| `budget.maxUSD` | 요청별 일일 예약액, 0 초과~1 USD |
| `budget.inputUSDPerMillion` | 확인한 100만 입력 토큰당 USD, 0 초과~1000 |
| `budget.outputUSDPerMillion` | 확인한 100만 출력 토큰당 USD, 0 초과~1000 |
| `budget.verifiedAt` | 가격을 확인한 Unix 밀리초. 미래 시각 또는 24시간 초과는 거부 |
| `budgetDirectory` | 예산 파일용 전용 절대 경로. 디렉터리 권한 0700 필요 |
| `dailyMaxUSD` | UTC 날짜별 예약 한도, 0 초과~100 USD |
| `port` | 기본 4179, 127.0.0.1에만 bind |

`verifiedAt`은 운영자가 확인했다는 입력값이지 자동 가격 검증이 아니다. 테스트 모델·가격을 실제 설정으로 재사용하지 않는다.

저장소 안에서 키 환경과 설정을 준비한 후 실행한다.

```sh
bun scripts/ai-summary-service.mjs /absolute/path/summary-config.json
```

출력된 로컬 주소를 직접 연다. 자동 브라우저 실행·백그라운드 등록·외부 호스트 공개는 하지 않는다. 중단은 Ctrl+C이며 진행 중 요청 취소나 비용 환불을 보장하지 않는다.

## 사용과 데이터 범위

1. JSON·JSONL·텍스트 형식의 한 대화 파일을 선택한다. 최대 8 MiB이며 자동 폴더 탐색은 없다.
2. 로컬 서버가 선택한 발언·모델·가격·예약액·전체 전송 JSON을 보여준다. 이 단계는 제공자 요청을 하지 않는다. 알려진 비밀값 제거는 불완전하므로 민감정보를 직접 확인한다.
3. 이번 요청에 동의한 뒤 생성한다. 5분 안에 승인해야 하고 같은 승인은 한 번만 사용한다. 토큰 계산과 요약 요청 모두 제공자에게 전송되며 실패해도 자동 재시도하지 않는다.
4. 목표·완료 주장·막힘·다음 행동을 실제 파일과 테스트에 대조하고 편집한다. AI의 근거 번호는 사실 검증이 아니다. 편집하면 검토 확인이 다시 해제된다.
5. 재검토 후 인계 JSON을 로컬 저장한다. 저장 파일은 네 항목과 출처 메타데이터만 포함하며 원문·근거·키는 제외한다. 편집값은 서버로 다시 보내지 않는다. 공개 Pocket에서 다시 열거나 새 세션에 직접 전달한다.

승인 세션은 메모리 전용이며 실행 중이 아닌 세션은 최대 5분 후 제거한다. 생성 후 화면에 남은 초안은 서버 세션 만료 뒤에도 검토·저장할 수 있다. 페이지를 닫거나 새로고침하면 미저장 화면 초안은 사라진다. 브라우저 Local Storage·Session Storage에는 저장하지 않는다.

지우기는 화면과 서버 삭제를 구분해서 안내한다. 서버에 연결하지 못해도 화면은 비우지만 서버 삭제를 확인했다고 말하지 않는다. 다운로드 파일과 이미 예약한 비용은 지우지 않는다.

## 비용과 보안 경계

제공자 호출 전에 요청별 최대 예약액 전액을 디스크 원장에 기록한다. 실패·응답 불명에도 유지하므로 실제 사용액보다 일일 한도에 먼저 도달할 수 있다. 토큰 기반 계산은 청구서나 절대 결제 상한이 아니다. 제공자 계정의 결제 제한도 별도로 설정해야 한다.

원장은 재시작 후 유지하며 손상·잠금·시계 역행 시 실행을 차단한다. 잠금 파일 자동 삭제·자동 예산 초기화는 없다. 별도 OS 프로세스 강제 종료 후 예약 보존, 12개 프로세스 동시 경합의 한도 보존, 종료된 잠금 보유자의 lock을 새 프로세스가 우회하지 않는 것을 합성 금액으로 검증했다. 전원 손실·디스크 오류·장기 실운영 검증은 남았다.

`budget_lock_unavailable`이면 실행 중인 동일 저장소 사용 프로세스가 있거나 중단된 실행의 잠금이 남았을 수 있다. 서비스 중복 실행을 먼저 확인한다. 예약 파일을 지우거나 새 저장 디렉터리로 바꾸어 한도를 우회하지 않는다. 손상 파일·남은 잠금의 복구는 원장과 증거를 보존한 운영자 점검이 필요하며 이 후보에 자동 복구는 없다.

화면과 API는 정확한 loopback origin, POST, Origin·Fetch Metadata·Bearer 인증으로 연결한다. 접근 토큰은 실행마다 생성하며 제공자 키와 다르다. CSP·no-store·CORS 차단·허용한 정적 파일만 제공하는 경계를 유지한다. 이 방식은 클라우드 로그인, 멀티계정 인증, 같은 사용자 권한의 악성 로컬 프로세스 방어를 대신하지 않는다.

## 합성 검증

`bash scripts/release-verify.sh --require-browser`는 가짜 제공자로 전송 동의·1회 생성·재검토·저장·삭제 실패 안내·화면 폭을 검증한다. 실제 대화나 유료 API는 사용하지 않으며 이 결과로 의미 요약 품질, 실제 작업 재개 또는 스토어 출시 완료를 주장하지 않는다.
